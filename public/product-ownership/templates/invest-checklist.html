INVEST Checklist

Does your user story meet these six criteria? If not, split it.

This is a preview of the A4 worksheet. Download the PDF to print it, or read User Stories and Acceptance Criteria for background.

User storyThe story you are checking
CriterionQuestionOK
IndependentCan be prioritised and understood on its own
NegotiableLeaves room to discuss the details, not a fixed specification
ValuableDelivers direct value to the user
EstimableDefined well enough to size roughly
SmallSmall enough to get feedback fast
TestableClear enough to know when it is done

If a story does not fit on the user story card, it is usually not small enough yet.
